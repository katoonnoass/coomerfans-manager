# Changelog

## 0.1.0

- Added profile search, favorites, and grouped favorites.
- Added fast/full profile refresh modes with progress logs and pause/cancel.
- Added media filters, virtualized grid/list, and bulk selection.
- Added native segmented downloads with validation, retry, and cooldown.
- Added IDM direct mode and `.ef2`/`.ief` import-file generation.
- Added grouped download queue controls.
- Added diagnostics page, notification history, activity dock, and repair actions.
- Added open-source documentation, Docker files, scripts, and CI.
